# Call routing

A transfer is requested only after confirmation. No real department number is bundled. The optional telephony adapter can report a failed transfer.

## Run locally

```sh
python -m voice_agents.demo routing
```

## Example dialogue

```text
You: billing
Agent: Would you like to be transferred to billing?
You: yes
Agent: Thank you. I will transfer you now.
```
