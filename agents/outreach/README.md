# Consent-first outreach

All dialogue is fictional. No commercial scripts, transactions, contact lists or bulk calling are included. A refusal ends the conversation.

## Run locally

```sh
python -m voice_agents.demo outreach
```

## Example dialogue

```text
You: yes
Agent: The fictional product is a free task-list demo. Would you like more information?
You: no
Agent: Thank you for your time. Goodbye.
```
